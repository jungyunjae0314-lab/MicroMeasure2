# 현미경 측정 (MicroMeasure) – 안드로이드 앱

폰에 현미경을 달고 찍은 사진에서 **픽셀 캘리브레이션 → 두 점 탭 → 실제 거리(µm/mm)** 를 보여주는 앱입니다.
안드로이드 10 이상에서 동작하며, 별도 권한이 필요 없습니다.

---

## APK 만드는 법 (택 1)

### 방법 A. GitHub로 자동 빌드 (PC에 설치할 것 없음, 추천)
1. github.com 가입 → 오른쪽 위 **+ → New repository** → 이름 `MicroMeasure` → **Create**
2. 생성된 저장소 화면에서 **uploading an existing file** 클릭
3. 이 압축을 푼 폴더 **안의 내용 전체**(`.github`, `app`, `gradle`, `gradlew` 등)를 끌어다 놓기 → **Commit changes**
   - `.github` 폴더가 꼭 같이 올라가야 자동 빌드됩니다.
4. 상단 **Actions** 탭 → `Build APK` 가 자동 실행됨 (약 3~5분, 초록색 ✔ 되면 완료)
   - 자동 실행이 안 되면 `Build APK` 선택 → **Run workflow**
5. 완료된 실행을 클릭 → 맨 아래 **Artifacts**의 `MicroMeasure-APK` 다운로드 → 압축 풀면 `MicroMeasure.apk`

### 방법 B. Android Studio
1. Android Studio 설치 → **Open** → 이 폴더 선택 (처음 동기화에 몇 분 걸림)
2. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**
3. `app/build/outputs/apk/debug/app-debug.apk` 생성

## 폰에 설치
1. APK 파일을 카톡·메일·USB 등으로 폰에 옮김
2. 파일을 열면 "출처를 알 수 없는 앱" 허용 화면 → 해당 앱(내 파일/카톡 등)에 **허용** → 설치
3. 회사 MDM 정책으로 막혀 있으면 IT 부서 승인 필요

## 사용법

### 1) 보정 (배율마다 한 번)
1. 현미경을 원하는 배율로 맞추고 **대물 마이크로미터(눈금자)** 를 촬영 (`📷 촬영` 또는 `🖼 갤러리`)
2. `📏 보정` → 눈금의 **시작점, 끝점**을 탭 (예: 0 ~ 1mm 눈금 양 끝)
3. 점을 손가락으로 끌면 왼쪽 위 **확대창**을 보면서 미세조정 (두 손가락으로 확대하면 더 정확)
4. `✔ 보정완료` → 배율 이름(예: `x100`) + 실제 길이(예: `1000 µm` 또는 `1 mm`) 입력 → 저장
   → µm/px 값이 폰에 저장됨

### 2) 측정
1. 같은 배율로 측정할 대상 촬영/불러오기
2. 상단 바 또는 `🔍 배율선택`에서 해당 배율 선택
3. 시작점 탭 → 끝점 탭 → 선 위에 거리 표시. 여러 개 연속 측정 가능
4. 끝점을 끌어서 미세조정, `↶ 취소` / `🗑 전체삭제`
5. `💾 저장` → 측정선이 그려진 사진(`Pictures/MicroMeasure`) + 측정값 CSV(`Download/MicroMeasure`)

### 정확도 팁
- 보정값은 **같은 배율 + 같은 카메라 줌 + 같은 해상도**에서만 유효합니다. 카메라 앱의 줌(1x/2x)을 바꾸면 다시 보정하세요.
  (해상도가 보정 때와 다르면 앱이 경고합니다)
- 렌즈 왜곡 때문에 **화면 중앙부**에서 재는 것이 정확합니다.
- 기준선은 **길게** 잡을수록(눈금 전체) 보정 오차가 줄어듭니다.
- 많이 확대하면 이미지가 픽셀 단위로 보여서 경계에 점을 정확히 찍을 수 있습니다.
